# Ciencia de Datos Aplicada (ITBA)

Repositorio de materiales del curso **Ciencia de Datos Aplicada** del Instituto Tecnológico de
Buenos Aires (ITBA), dictado para la Ingeniería en Informática y la Licenciatura en Negocios y
Tecnología por Mg. Juan Manuel Fernández y Mg. Diego Gasch.

Sitio del curso: https://jumafernandez.github.io/itba-data-science/

## De qué se trata

La ciencia de datos se aprende haciendo. Este curso recorre el ciclo completo de un proyecto de
datos con la mirada puesta en problemas reales: conseguir los datos donde estén, aunque sea
a través de una página web que no tiene API; explorarlos, limpiarlos y transformarlos; entrenar
y evaluar modelos que respondan una pregunta concreta; y llevar esos modelos a producción como
aplicaciones y servicios que otros puedan usar.

Cada tema se trabaja en dos planos. Por un lado, los fundamentos: qué es lo que está pasando y
por qué funciona. Por el otro, la práctica con las herramientas del ecosistema Python que se
usan en la industria: `requests`, `BeautifulSoup`, Selenium y Playwright para obtener datos;
`pandas` y `scikit-learn` para analizarlos y modelar; Flask y Streamlit para desplegar; y los
modelos de lenguaje como una capa nueva que permite automatizar tareas que hasta hace poco
requerían programar cada paso.

## Qué se puede encontrar acá

El repositorio crece a medida que avanza el curso. Los materiales que aparecen son de este tipo:

- **Código de las clases**: los scripts y notebooks que se muestran en vivo, pensados para que
  se puedan volver a ejecutar en casa y modificar.
- **Páginas de práctica**: sitios web preparados especialmente para los ejercicios de scraping,
  publicados en GitHub Pages para que se comporten como un sitio real.
- **Actividades integradoras**: consignas y datasets de los trabajos que atraviesan varias
  unidades, desde el análisis exploratorio hasta el diseño de un modelo.
- **Aplicaciones de ejemplo**: pequeñas apps completas que muestran cómo se empaqueta y se
  expone un modelo entrenado.
- **Resoluciones**: versiones resueltas de los desafíos propuestos en clase, escritas con código
  simple y comentado.

Cada carpeta es autónoma, con sus dependencias y, cuando hace falta, un README con el paso a paso
para ejecutar el material. Un buen punto de partida es la unidad de
[web scraping](web-scraping/README.md).

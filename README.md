# Ciencia de Datos Aplicada (ITBA)

Repositorio del curso Ciencia de Datos Aplicada para la Ingeniería en Informática y la
Licenciatura en Negocios y Tecnología del Instituto Tecnológico de Buenos Aires.

Docentes: Mg. Juan Manuel Fernández y Mg. Diego Gasch.

## Contenido

- [`web-scraping/`](web-scraping/): obtención de datos de páginas web con requests, BeautifulSoup, Selenium y Playwright. Ver su [README](web-scraping/README.md).
- [`actividad_integradora_preentrenga02/`](actividad_integradora_preentrenga02/): actividad integradora de clasificación supervisada.
- [`model-app-flask/`](model-app-flask/) y [`model-app-streamlit/`](model-app-streamlit/): despliegue de un modelo entrenado como aplicación web.

Cada carpeta tiene su propio `requirements.txt`.
